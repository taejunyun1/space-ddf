# 모바일 Exhibition Field + Space Rental 하단 도크 명세

## 목적

모바일 사용자가 스크롤하지 않아도 전시 탐색 기능과 대관 신청 진입점을 확인할 수 있도록 `Exhibition Field`와 `Space Rental`을 하나의 화면 하단 도크로 묶는다.

## 확정 동작

- 폭 768px 이하에서 `Exhibition Field`와 `Space Rental`을 하나의 그룹으로 화면 최하단에 고정한다.
- 두 요소 사이 간격은 0px이다.
- `Space Rental`은 40px 높이의 한 줄 CTA로 압축한다.
- 본문에는 실제 도크 높이만큼 하단 여백을 두어 콘텐츠가 가려지지 않게 한다.
- 사이드 메뉴가 열려 있을 때 도크는 메뉴 뒤에 숨는다.
- 폭 769px 이상에서는 현재 데스크톱 문서 흐름과 크기를 유지한다.
- iOS safe-area는 빨간 CTA 내부에 필요한 만큼만 더한다.

## 검증

- 회귀 테스트로 모바일 고정 위치, 0px 간격, 40px CTA, 본문 하단 여백을 고정한다.
- 전체 테스트, 린트, production 빌드를 실행한다.
- 390px 실제 브라우저에서 초기 화면의 도크 노출과 가로 오버플로 부재를 확인한다.
- production 배포 후 실제 도메인에서 동일 동작을 확인한다.
