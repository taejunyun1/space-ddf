# `/admin` 관리자 통합 설계

## 목표

렌탈 관리와 콘텐츠 관리를 하나의 관리자 화면으로 통합한다. 관리자가 사용하는 프론트엔드 주소는 `/admin` 하나만 제공한다.

## 라우팅

- `/admin`만 관리자 프론트엔드 라우트로 등록한다.
- `/admin/rental`, `/admin/rentals`, `/admin/contents`, `/manage`, `/manage/rentals`, `/manage/contents`, `/manage/contents/:id/preview` 라우트는 삭제한다.
- 삭제한 주소에 리다이렉트를 두지 않는다. 해당 주소는 일반 404 화면으로 처리한다.
- 관리자 API 주소는 프론트 주소가 아니므로 기존 `/api/manage/*`를 유지한다.
- Cloudflare Pages 관리자 인증 함수는 `/admin` 요청만 앱 셸로 전달한다.

## 화면 구조

`AdminView.vue`를 `/admin`의 단일 진입점으로 둔다.

- 상단 헤더에 `렌탈 관리`, `콘텐츠 관리` 탭을 제공한다.
- 탭 상태는 화면 내부 상태로 관리하며 주소를 변경하지 않는다.
- 첫 진입 시 렌탈 관리 탭을 연다.
- 기존 `AdminRentalsView.vue`와 `AdminContentsView.vue`의 기능을 재사용 가능한 패널로 유지한다.
- 각 패널에 있던 중복 관리자 내비게이션은 제거한다.

## 콘텐츠 미리보기

- 콘텐츠 미리보기는 새 주소나 새 창을 열지 않는다.
- `/admin` 화면 위에 전체화면 모달로 표시한다.
- 닫기 버튼과 `Escape` 키로 편집 화면에 돌아간다.
- 미리보기 데이터는 현재 편집 중인 초안을 사용한다.

## 오류와 접근성

- 탭은 버튼으로 구현하고 현재 탭을 `aria-selected`로 노출한다.
- 키보드 포커스가 명확히 보이게 한다.
- 미리보기 모달은 대화상자 역할과 제목을 제공한다.
- 각 렌탈·콘텐츠 기능의 기존 로딩 및 오류 처리는 그대로 보존한다.

## 테스트

- 라우터에 관리자 프론트 경로가 `/admin` 하나만 존재하는지 검증한다.
- 삭제 대상 경로 문자열이 라우터와 관리자 내비게이션에 남지 않았는지 검증한다.
- 통합 화면에 두 탭과 두 관리 패널이 연결되는지 검증한다.
- 콘텐츠 미리보기가 URL 이동 대신 내부 모달을 여는지 검증한다.
- 전체 테스트, 린트, 프로덕션 빌드를 실행한다.
