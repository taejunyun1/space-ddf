# Recent 포스터 전용 표시와 Instagram 아이콘 설계

## 목표

홈의 `Recent Updated`에는 최신 공개 콘텐츠의 포스터만 표시한다. 상세 페이지의 참여작가 Instagram URL은 텍스트 대신 이름 옆 SVG 아이콘 링크로 표시한다.

## Recent Updated

- `Recent Updated` 섹션 제목은 유지한다.
- 섹션 본문에는 최신 공개 콘텐츠의 포스터만 표시한다.
- 포스터 전체를 기존 상세 페이지 링크로 사용한다.
- Recent 카드의 콘텐츠 제목, 날짜, 크레딧, 설명, `자세히 보기` 문구는 모두 제거한다.
- 포스터 이미지의 대체문구는 콘텐츠 제목을 포함해 접근성을 유지한다.
- 데스크톱과 모바일 모두 포스터 원본 비율을 유지하며 잘라내지 않는다.
- 최신 공개 콘텐츠를 선택하는 서버 featured 규칙은 변경하지 않는다.

## 상세 페이지 Instagram 링크

- 크레딧 마지막 URL의 hostname이 `instagram.com` 또는 그 하위 도메인이면 Instagram 링크로 분류한다.
- 크레딧의 역할과 이름 텍스트는 그대로 표시한다. URL 문자열만 숨긴다.
- 이름 뒤에 16px 인라인 SVG Instagram 아이콘 링크를 표시한다.
- 아이콘은 `currentColor`를 사용하고 기존 크레딧 색상과 정렬을 따른다.
- 링크는 새 탭에서 열고 `rel="noopener noreferrer"`를 유지한다.
- 링크의 접근성 이름은 크레딧 이름을 포함한 `Instagram 열기` 문구로 제공한다.
- Instagram이 아닌 홈페이지 등 외부 링크는 기존 URL 텍스트 링크 표현을 유지한다.
- URL이 없거나 유효하지 않은 크레딧은 기존 일반 텍스트로 표시한다.

## 구현 경계

- Instagram SVG는 상세 페이지에서 재사용 가능한 작은 컴포넌트로 분리한다.
- URL 파싱 결과에 링크 종류를 추가하고 템플릿이 종류에 따라 SVG 또는 텍스트 링크를 선택한다.
- 어드민 저장 형식과 D1 공개 payload는 변경하지 않는다.
- 기존 `<멸망 언박싱>` 데이터는 다시 입력하거나 보정하지 않는다.

## 검증

- Recent 컴포넌트에 포스터와 상세 링크만 남고 메타 텍스트가 없는지 테스트한다.
- Instagram URL이 링크 종류로 식별되고 SVG 아이콘으로 렌더링되는지 테스트한다.
- 일반 홈페이지 링크가 텍스트 링크로 유지되는지 테스트한다.
- 링크의 새 탭, 보안 속성, 접근성 라벨을 테스트한다.
- 데스크톱과 390px 모바일에서 포스터 비율, 클릭 영역, 상세 페이지 아이콘 정렬, 가로 넘침을 브라우저로 확인한다.
- 전체 lint, 테스트, Pages 빌드와 운영 스모크 테스트를 통과한 뒤 배포한다.
