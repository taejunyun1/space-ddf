# 전시지도 레이더 통합 설계

## 목표

별도의 전시 레이더 페이지를 추가하지 않고 기존 `/archive-map`을 현재 진행 중인 전시를 탐색하고 방문 경로를 구성하는 중심 화면으로 개선한다. 기존 `/archive-route`는 다중 경유 길찾기 전용 화면으로 유지하며, 두 화면을 공통 탭과 URL 쿼리로 연결한다.

서울시와 같은 실시간 인구밀집 데이터가 없으므로 혼잡도, 혼잡 예상, 혼잡 등급과 관련된 UI 및 계산 로직은 만들지 않는다. 화면에는 공식 데이터와 현재 아카이브 데이터에서 확인 가능한 정보만 표시한다.

## 정보 구조와 라우팅

- `/archive-map`: 전시지도 탭. 현재 진행 중인 전시 탐색, 필터링, 지도 확인, 경로 대상 선택을 담당한다.
- `/archive-route`: 길찾기 탭. 선택한 전시의 순서 조정, 출발점·교통수단 선택, 주변 교통 확인, 네이버 지도 실행을 담당한다.
- 두 페이지 상단에 같은 모양과 순서의 `전시지도`, `길찾기` 탭을 배치한다.
- 현재 페이지의 탭은 검은 배경과 흰 글자로 표시하고 `aria-current="page"`를 제공한다.
- 데스크톱과 모바일 모두 두 탭을 동일하게 제공한다. 모바일에서는 메뉴 안에 숨기지 않고 콘텐츠 상단에 가로 2분할로 고정한다.
- 전시지도에서 길찾기로 이동할 때 선택한 전시 ID를 기존 `to` 쿼리 규약으로 전달한다.
- 길찾기에서 전시지도로 돌아갈 때도 `to` 쿼리를 유지해 선택 상태를 복원한다.
- URL 공유와 브라우저 뒤로가기가 정상 동작하도록 선택 상태의 기준은 URL 쿼리로 둔다.

## 전시지도 화면

### 상단 탐색과 검색

- 기존 DDF 헤더와 디자인 토큰을 유지한다.
- 공통 탭 아래에 검색창과 현재 위치 버튼을 배치한다.
- 검색 대상은 전시명, 공간명, 지역명이다.
- 현재 위치를 허용하면 목록을 거리순으로 정렬할 수 있고 각 항목에 거리를 표시한다.
- 위치 권한을 거부하거나 좌표를 얻지 못해도 페이지의 나머지 기능은 정상 동작한다. 이때 거리 표시와 거리순 정렬만 숨긴다.

### 필터와 정렬

- 기존 지역, 전시 유형 필터를 유지한다.
- 빠른 필터는 `전체`, `오늘 종료`, `무료`, `주차 가능`을 제공한다.
- `오늘 종료`는 Asia/Seoul 날짜 기준으로 종료일이 오늘인 전시다.
- `무료`는 데이터에 무료 관람 여부가 명시된 경우에만 포함한다. 정보가 없는 전시를 무료로 추정하지 않는다.
- `주차 가능`은 주변 교통 API에서 확인된 공영주차장이 있는 전시만 포함한다.
- 기본 정렬은 현재 데이터의 안정적인 시간순 정렬을 유지한다. 위치가 확보되면 사용자가 `가까운 순`을 선택할 수 있다.
- 종료일이 지난 전시는 지도와 레이더 목록에서 모두 제외한다.

### 지도와 전시 목록

- 데스크톱은 목록과 지도를 나란히 표시하고, 모바일은 기존 합의대로 지도와 리스트를 탭으로 전환한다.
- 마커는 혼잡 상태 색상을 사용하지 않는다. DDF 기본색으로 통일하고 `오늘 종료`만 보조 강조색과 텍스트로 구분한다.
- 목록 항목에는 확인 가능한 정보만 노출한다: 전시명, 공간명, 기간, 운영시간, 거리, 무료 여부, 주변 버스·지하철·공영주차장 요약.
- 없는 운영시간, 가격, 교통 정보는 빈 라벨을 만들지 않고 해당 행 자체를 숨긴다.
- 기존 원문 보기와 전시 상세 동작을 유지한다.
- 교통 정보는 모든 전시에 한꺼번에 요청하지 않는다. 화면에 상세 선택된 전시 또는 사용자가 펼친 전시에만 `/api/archive/nearby`를 요청해 API 호출량을 제한한다.

## 경로 선택과 길찾기 연결

- 전시 목록과 지도 상세에 `경로에 추가` 또는 `선택됨` 컨트롤을 제공한다.
- 선택 순서는 사용자가 추가한 순서대로 유지한다.
- 네이버 지도 경로 규약에 맞춰 출발점을 제외한 전시 선택은 최대 6곳으로 제한한다.
- 제한에 도달하면 나머지 추가 버튼을 비활성화하고, `경로는 최대 6곳까지 선택할 수 있습니다`라는 상태 안내를 표시한다.
- 선택된 개수와 전시명을 보여주는 경로 요약 바를 제공한다.
- 요약 바의 주 행동은 `길찾기에서 순서 정하기`이며 `/archive-route?to=...`로 이동한다.
- 선택이 없을 때 길찾기 탭을 누르면 빈 길찾기 페이지로 이동하고 사용자가 해당 화면에서 전시를 선택할 수 있다.
- `/archive-route`의 기존 현재 위치 요청, 고정 출발점, 순서 변경, 대중교통 정보, 네이버 앱·웹 실행 기능은 유지한다.

## 데이터 흐름과 계산 경계

1. 기존 아카이브 API와 정적 폴백 데이터를 불러온다.
2. Asia/Seoul 날짜 기준으로 진행 중 전시만 계산한다.
3. 검색, 지역, 유형, 빠른 필터를 순서대로 적용한다.
4. 현재 위치가 있으면 클라이언트에서 거리만 계산하고 정렬에 사용한다.
5. 선택 ID는 `to` 쿼리에서 읽고, 진행 중이며 좌표가 유효한 전시만 복원한다.
6. 상세 선택된 전시에만 주변 교통 API를 요청한다.
7. 길찾기 이동 시 현재 선택 순서를 그대로 `to` 쿼리에 직렬화한다.

혼잡도나 방문객 수를 추론하는 데이터 흐름은 포함하지 않는다.

## 컴포넌트 경계

- `ArchiveModeTabs`: 전시지도와 길찾기 공통 탭, 쿼리 보존을 담당한다.
- `ArchiveFilters`: 기존 필터에 빠른 필터와 정렬 선택을 추가한다.
- `ArchiveList`: 전시 정보, 오늘 종료, 거리, 교통 요약, 경로 선택 컨트롤을 표시한다.
- `ArchiveMap`: 진행 중 마커, 오늘 종료 강조, 경로 선택 상태를 표시한다.
- `ArchiveRouteSelectionBar`: 선택 개수, 최대 제한, 선택 요약, 길찾기 이동을 담당한다.
- `useRegionalArchive`: 진행 상태, 필터, 정렬, 현재 위치와 선택 쿼리의 파생 상태를 담당한다.
- 기존 `archive-route.mjs`의 ID 직렬화와 네이버 경로 제한 규약을 두 페이지가 공유한다.

컴포넌트가 API 원본을 직접 추정하거나 보정하지 않도록 데이터 정규화와 파생 계산은 composable 및 라이브러리에 둔다.

## 오류와 빈 상태

- 아카이브 API 실패 시 기존 정적 데이터 폴백을 유지하고 화면에는 불필요한 오류 세부정보를 노출하지 않는다.
- 현재 진행 중인 전시가 없으면 `현재 진행 중인 전시가 없습니다`와 필터 초기화 행동을 제공한다.
- 필터 결과만 비었으면 `조건에 맞는 전시가 없습니다`와 `필터 초기화`를 제공한다.
- 위치 권한 거부는 비차단 안내로 표시하고 검색·지도·수동 경로 선택을 계속 사용할 수 있게 한다.
- 주변 교통 API 실패 시 해당 교통 요약만 숨기거나 재시도 행동을 제공하고 전시 선택과 길찾기는 차단하지 않는다.
- URL에 종료된 전시, 알 수 없는 ID, 좌표가 없는 ID가 들어오면 조용히 제거하고 정상화된 쿼리로 교체한다.

## 접근성과 반응형

- 공통 탭은 키보드로 이동 가능하며 활성 상태를 텍스트와 `aria-current`로 함께 전달한다.
- 필터와 경로 선택은 실제 버튼·체크박스 요소를 사용하고 색상만으로 상태를 전달하지 않는다.
- 위치, 교통, 오늘 종료 상태에는 화면 낭독기용 문구를 제공한다.
- 모바일에서 가로 스크롤이 생기지 않도록 필터는 한 줄 스크롤 또는 줄바꿈을 사용한다.
- 경로 요약 바는 콘텐츠를 가리지 않으며 safe-area 하단 여백을 반영한다.
- 지도만으로 정보를 전달하지 않고 같은 전시 목록을 항상 사용할 수 있게 한다.

## QA 및 완료 조건

### 자동 테스트

- 전시지도와 길찾기 양쪽에 공통 탭이 있고 쿼리를 보존한다.
- 종료된 전시는 지도·목록·선택 복원에서 제외된다.
- 오늘 종료 필터가 Asia/Seoul 날짜 경계에서 정확히 동작한다.
- 무료와 주차 가능은 확인된 데이터만 사용하고 정보가 없으면 포함하지 않는다.
- 현재 위치가 없을 때 거리 UI와 거리 정렬이 숨겨진다.
- 선택 순서와 최대 6곳 제한이 두 페이지에서 동일하다.
- 잘못된 `to` 쿼리는 안전하게 정규화된다.
- 교통 API는 상세 선택된 전시에만 호출된다.
- 혼잡도 관련 텍스트와 계산 코드가 전시지도 의존 그래프에 없다.

### 브라우저 QA

- 데스크톱: 목록·지도·탭·경로 요약의 시각적 계층과 선택 흐름을 확인한다.
- 모바일: 지도/리스트 전환, 필터 스크롤, 하단 경로 요약, safe-area를 확인한다.
- 현재 위치 허용·거부 양쪽을 확인한다.
- 전시 1곳과 6곳 선택, 7번째 선택 차단을 확인한다.
- 전시지도에서 길찾기로 이동한 뒤 선택 순서가 유지되는지 확인한다.
- 길찾기에서 전시지도로 돌아온 뒤 선택 상태가 유지되는지 확인한다.
- 네이버 지도 앱과 웹 실행이 기존처럼 동작하는지 확인한다.

### 배포 완료 조건

- 전체 테스트, 린트, Pages 프로덕션 빌드가 통과한다.
- 배포 미리보기와 `spaceddf.xyz`에서 두 경로가 HTTP 200으로 응답한다.
- 기존 전시 아카이브, 길찾기, 관리자 업로드 기능에 회귀가 없다.

## 제외 범위

- 실시간 또는 예상 혼잡도
- 방문객 수 추정
- 통신사 유동인구 데이터 연동
- 새로운 `/exhibition-radar` 라우트
- 네이버 지도 내부 경로 계산을 DDF 서버에서 재구현하는 작업
