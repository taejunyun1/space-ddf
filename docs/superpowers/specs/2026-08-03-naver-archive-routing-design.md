# 네이버 지도 전시 경로 교체 설계

## 목표

지역 아카이브의 독립 길찾기 페이지에서 Google Maps 길찾기 링크를 네이버 지도 연동으로 교체한다. 국내 장소 인식 정확도를 높이고, 현재 위치·ACC·광주비엔날레 출발지와 여러 전시장 방문 순서를 유지한다.

## 범위

- `/archive-route`의 외부 길찾기 링크와 관련 안내 문구를 네이버 지도로 교체한다.
- 아카이빙 지도 자체와 사이트 공통 위치 지도는 이번 변경 범위에 포함하지 않는다.
- 외부 유료 경로 API를 호출하거나 사이트 안에 경로 지도를 새로 렌더링하지 않는다.

## 연동 방식

네이버 지도 공식 URL Scheme을 사용한다. 모든 장소는 이름이나 주소 검색 대신 수집된 위도·경도를 우선 전달한다.

- 현재 위치 출발은 `slat`, `slng`를 생략한다.
- ACC와 광주비엔날레 출발은 고정 좌표와 이름을 전달한다.
- 도착지는 `dlat`, `dlng`, `dname`으로 전달한다.
- 경유지는 방문 순서대로 `v1`부터 `v5`까지 전달한다.
- `appname`은 `https://spaceddf.xyz`로 고정한다.
- 동일 좌표의 여러 전시는 하나의 방문 장소로 합친다.

## 이동 방식

- 한 장소의 `추천`과 `대중교통`은 `/route/public`을 사용한다.
- 한 장소의 `자동차·주차`는 `/route/car`를 사용한다.
- 두 장소 이상은 네이버 지도의 다중 경유가 확실하게 지원되는 `/route/car`를 사용한다.
- 경유지는 공식 규격에 맞춰 최대 5곳으로 제한한다. 따라서 한 번에 전달하는 고유 장소는 경유지 5곳과 최종 도착지 1곳, 총 6곳이다.
- 선택 항목이 총 6곳을 넘으면 화면에 제한 안내를 표시하고, URL에는 앞에서부터 6개의 고유 장소만 포함한다.

## 모바일 및 PC 동작

- 기본 버튼은 `네이버 지도로 경로 열기`로 표시한다.
- 모바일에서는 `nmap://` URL Scheme으로 네이버 지도 앱을 연다.
- PC 또는 앱 실행이 불가능한 환경에서는 네이버 지도 웹 길찾기 화면을 새 창으로 연다.
- 앱 설치 유도 때문에 현재 페이지가 사라지지 않도록 외부 연결은 새 창 또는 새 탭을 사용한다.

## 사용자 화면

- 페이지 상단의 Google Maps 문구를 네이버 지도로 교체한다.
- 다중 장소를 선택하면서 추천 또는 대중교통을 선택한 경우, 다중 경유는 자동차 경로로 열린다는 안내를 유지하되 네이버 지도 기준 문구로 변경한다.
- 동일 전시장에서 여러 전시가 선택된 경우에는 전시 선택 상태는 유지하고, 외부 경로에서만 하나의 장소로 합친다.
- 경로 제한으로 일부 장소가 제외되면 포함되는 장소 수를 명확히 안내한다.

## 오류 처리

- 유효한 좌표가 없는 항목은 외부 경로에서 제외한다.
- 모든 선택 항목에 유효한 좌표가 없으면 길찾기 버튼을 비활성화하고 안내 문구를 표시한다.
- 네이버 지도 앱 실행 실패 시 웹 길찾기 화면으로 이동할 수 있는 보조 동작을 제공한다.

## 검증

- 현재 위치에서 단일 전시장 대중교통 URL을 검증한다.
- ACC 및 광주비엔날레 고정 출발 좌표를 검증한다.
- 동일 좌표 중복 제거와 방문 순서를 검증한다.
- 네이버 경유지 `v1`~`v5`와 최종 목적지 매핑을 검증한다.
- 6곳 초과 선택 시 제한과 안내를 검증한다.
- Google 길찾기 URL과 Google Maps 안내 문구가 `/archive-route` 의존성에서 제거됐는지 검증한다.
- 전체 테스트, 린트, Pages 프로덕션 빌드 후 운영 도메인 번들을 확인한다.
