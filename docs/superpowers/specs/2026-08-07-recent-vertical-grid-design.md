# Recent Updated 세로 스크롤 그리드 명세

## 목적

홈의 `Recent Updated`에서 가로 오버플로와 좌우 스크롤을 제거한다. 모든 포스터는 현재 뷰포트 안에서 줄바꿈되며 사용자는 페이지의 세로 스크롤만 사용한다.

## 확정 레이아웃

- 데스크톱: 동일 폭 3열
- 태블릿: 동일 폭 2열
- 모바일: 1열
- 기존 포스터 종횡비, 이미지 `object-fit: cover`, 선 기반 카드 스타일을 유지한다.
- `overflow-x`와 scroll snap을 제거한다.
- 카드 최소 폭 때문에 페이지 전체에 가로 스크롤이 생기지 않도록 각 열과 링크에 `min-width: 0`을 적용한다.

## 반응형 기준

- 기본: 3열
- `max-width: 1100px`: 2열
- `max-width: 768px`: 1열

## 검증

- 소스 회귀 테스트로 3/2/1열 규칙과 가로 오버플로 제거를 고정한다.
- 전체 테스트, 린트, production 빌드를 실행한다.
- 데스크톱과 모바일 뷰포트에서 문서의 `scrollWidth`가 `clientWidth`를 넘지 않는지 확인한다.
- production 배포 후 실제 도메인의 새 자산 해시와 HTTP 200을 확인한다.
